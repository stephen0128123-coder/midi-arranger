# MIDI 改编台

在浏览器里把 MIDI 改编成七音竖笛或九音手碟谱。竖笛输出单旋律，手碟可保留和弦。

## 使用方法

1. 在仓库页面点 **Code → Download ZIP**，解压后双击「MIDI 改编台.html」。建议使用 Edge 或 Chrome，断网也能打开。
2. 拖入 `.mid` 或 `.midi` 文件，选择竖笛或手碟，再点击生成。页面也内置了小星星示例。
3. 对比试听原曲、提取旋律和改编版。可以切换主旋律候选、分段指定音轨或自定义乐器音高。
4. 点 **下载键盘谱 TXT** 导出按键、时间、时值和休止。方括号里的键同时按下，例如 `[B+F]`。也可以下载改编 MIDI 或原音高的提取旋律 MIDI。

| 模式 | 默认键位 |
| --- | --- |
| 七音竖笛 | A S D F J K L |
| 九音手碟 | B F G H J K T Y U |

导入上限为 60 分钟、20 MB、20 万个非打击乐音符。导入、转换和试听均在本机浏览器中完成。
